# task-management-system
Production-grade full-stack architecture built with Spring Boot, Angular, and PostgreSQL. Features fine-grained RBAC security, transactional email integration, distributed rate limiting, decoupled cloud deployment, and comprehensive test suites.

## 🌐 Live Deployments

* **Frontend App:** [tms-frontend-beige.vercel.app](https://tms-frontend-beige.vercel.app) *(Angular v17 on Vercel)*
* **Backend API:** [tms-backend-lh6q.onrender.com](https://tms-backend-lh6q.onrender.com) *(Spring Boot on Render)*

> 💡 **Instance Spinning Notice:** The backend is hosted on a free Render web service. If idle, the initial request may take 30–45 seconds to spin up the container.
